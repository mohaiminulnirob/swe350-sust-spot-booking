## 📝 LinkedIn Post Text (Recommended)

```markdown
🏛️ Campus venue booking, fully digitized!

I'm excited to share the **SUST Spot Booking Platform** — a full-stack web application built for Shahjalal University of Science and Technology as part of our **SWE 350** course. This platform replaces the entire manual venue reservation process with a seamless, digital, end-to-end workflow.

**What it does:**
The platform serves three user roles — students/faculty (internal), external organizers, and admins. Internal users register with their @sust.edu email, while external users sign up with organization details and ID verification. All users can browse campus spots, check real-time availability via an interactive color-coded calendar (Day/Night/Full Day sessions), submit booking requests with faculty recommender assignment, and track approvals through a multi-step sequential pipeline. Once fully approved, the system generates an official PDF approval copy with digitized signatures. A built-in blog system lets organizers publish event recaps with photo galleries, schedules, and moderated attendee feedback. Admins get a full dashboard with analytics, spot CRUD, blog moderation, conflict-free slot reservations, and downloadable booking reports. Real-time notifications (polling every 15s) keep everyone updated.

✨ **Key Features:**
* 👥 **Dual Registration:** Tailored flows for Internal (@sust.edu) and External organizers (with ID upload)
* 📅 **Availability Calendar:** Interactive color-coded calendar (red=booked, yellow=partial, teal=pending)
* ✍️ **Recommendation Gate:** Bookings route to faculty recommenders before admin approval
* 🔒 **Multi-Step Sequential Approval:** Configurable approval chains per spot with PDF + digital signature generation
* 📝 **Event Blogs & Feedback:** Post-event recaps with galleries, schedules, and moderated reviews
* ⚡ **Conflict-Free Admin Bookings:** Direct slot reservation with auto-cancellation of conflicting requests
* 🔔 **Real-Time Notifications:** Bell icon with unread badge, auto-polling every 15 seconds

🛠️ **Tech Stack:** React 19, Vite 7, Tailwind CSS 4, React Router 7, Axios, Node.js, Express 5, MySQL, JWT, Bcryptjs, Nodemailer, Cloudinary, Multer
```

## 📹 Video Production Plan

### 1. Pre-Recording Checklist
* **Populate Mock Data:** Ensure the database has 3-4 spots with images, an external user registered, a pending booking, a faculty recommender account, an admin account, and 1-2 published blogs.
* **Theme & Zoom:** Set browser zoom to 100%-110% for readability on mobile. Use a clean browser profile.
* **Recording Tool:** [OBS Studio](https://obsproject.com/) (free) or [Loom](https://www.loom.com/) — capture at 1080p, 60 FPS.

### 2. Recording Sequence (Already Recorded ✓)
1. **Landing + Login** — Show landing page, then log in as an internal user.
2. **External Flow** — Show external registration and login.
3. **Booking Cycle** — Full cycle: user books → faculty recommends → admin approves → PDF generated.
4. **Blog** — Show published event blog with gallery and feedback.
5. **Admin** — Dashboard analytics, spot management, blog moderation.

### 3. Post-Production Tips
* **Trim & Speed Up:** Cut out loading/typing pauses. Speed up form fills to 2x-3x.
* **AI Voiceover:** Use the scripts above with any free TTS tool. Sync each scene's audio clip to its visual.
* **Background Music:** Add a low-volume (-20dB) corporate/tech track from [Pixabay Music](https://pixabay.com/music/) (free).
* **Zoom-Ins:** Add digital zoom on key actions (calendar selection, Approve button, PDF output) to guide the viewer's eye.
